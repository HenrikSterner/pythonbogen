Python Turtle

Klar

Tegn med Python – og se hvert skridt.

Start med blokke, skift til ægte Python, eller vælg et eksempel. Alle programmer i biblioteket er Python Turtle-kode. Blokke og tekst synkroniseres for de blokvenlige kommandoer; mere avancerede Python-linjer bevares som Python-linjer i Blockly.

Sådan bruger du detVælg et eksempel → tryk Kør → prøv Ét trin → se variablerne ændre sig.
Blokke genererer Python med det samme. Python læses tilbage til blokke, når du holder pause i skrivningen.

De lilla Turtle-blokke svarer direkte til Python-linjer som t.forward(100). Brug “Rå Python-linje” til noget, Blockly ikke har en blok for.
